# 走向卓越丨提升领导力，促学科发展——国家皮肤与免疫疾病临床医学研究中心举办第一届全国中青年皮肤科主任论坛

> 更新时间：2026-09-11 (UTC+8)

今年5月，我院作为唯一被公示的皮肤科领域单位，获批国家皮肤与免疫疾病临床医学研究中心。为了发挥示范引领作用，团结带领全国医疗机构的皮肤科进一步加强学科建设，国家皮肤与免疫疾病临床医学研究中心开设了“中国皮肤科主任领导力学院”，与全球著名的战略人力资源和领导力体系咨询公司RBL合作，精心设计了多模块的领导力发展课程。这一举措旨在促进学科带头人提升领导力，为皮肤医学界培养领军人才与管理人才，可谓学界的“黄埔军校”。

近日，第一届全国中青年皮肤科主任论坛在上海召开。国家皮肤与免疫疾病临床医学研究中心常务副主任、我院皮肤性病科主任李航教授为论坛开幕致辞，欢迎了来自全国各地著名医院的十几位皮肤科主任，并宣布中国皮肤科主任领导力学院“黄埔一期”正式开课。
**第一届全国中青年皮肤科主任论坛**
开课之前，中国皮肤医学界泰斗、北京大学第一医院朱学骏教授来到课堂，分享了他从医数十年的心路历程，以及他当初担任科室主任时的科室管理经验。他意味深长地和各位科室主任寄语：“当你选择做了医生，你便拥有了主宰人命运的职业，当你的名声越大，资历越高，就意味着你承载的责任越大。”他希望各位主任能够有所担当，提升领导力，推动团队实现长足进步。

探索领导力密码
来自RBL集团的资深人力资源经理Roy Gao带领各位科主任走上了领导力发展的探索之旅。

授课老师向大家抛出了备课时的疑惑：这一课堂上，大家要学习什么？在一个专业性极强的工作环境中，倡导商业界里的“领导力”概念，大家会接受么？诸位主任们面对的问题和挑战，“领导力”能够解答吗？
从理论框架切入
在疑惑和忐忑中，“领导力”培训之旅启程了。让人惊讶的是，在刚刚阐述了RBL领导力密码的框架，以及交响乐和爵士乐的组织之后，便得到了在座医生茅塞顿开般的强烈共鸣。

科室主任们和各位公司管理者们一样，面对着来自多方面的矛盾：既要提升当下科室的临床工作效率，又要为科室未来的发展出主意、定战略；既要为科室的发展筹措资源，又要为医学的发展持续科研，找到新的诊疗方法。

《领导力密码》恰恰强调了领导者在管理岗位上的多重角色。领导者既要关注眼前的事务，又要筹划未来的发展；既要关切每一个个体，也要注重大家的集体。所以《领导力密码》提出的领导力素质包括：

1.  战略家=未来+集体

2.  执行者=现在+集体

3.  人才管理者=现在+个体

4.  人力资本发展者=未来+个体

而要管理好以上这些千头万绪的工作，还需要领导者对自己高度自知，并严格管理，真正做到知行合一，于是有了第5项：个人高效。
制定战略也有方法可询
有了理论框架，诸位主任立刻厘清了自己作为科室领头人的职责所在，课程为主任们设计的发展路线，就沿着这个框架，从科室发展的大方向入手，让科室主任们第一次体验了烧脑的“战略讨论”，大家发现，制定战略也有方法可循。

战略的话题可以很高深也可以很落地。秉承RBL一贯由外而内的管理哲学，课程从现在医疗体系的大方向开始分析，再逐步了解各个区域的发展差异，接着深入探讨每个医院和科室的能力差异。围绕着问题：“我要建立一个什么样的科室？”每一个科室主任都理解了战略制定的思路框架，并被附赠了一套分析工具，帮助主任把方法带回科室，继续深入探讨。
以患者为中心的思维方式
方法论和分析工具都是硬核的内容，但很多时候框架再硬也没用，还需要软性的文化和行为的支持。在商业环境里，需要以客户为中心的思维模式；而在行医环境里，医生们就需要发展以患者为中心的思维方式。

医生面对的患者到底是谁？医生想要的患者是谁？医生如何满足患者的期待？科室所有人又该用怎样的行为，表达“以患者为中心”的思想呢？

这些深度思考与分析让科室主任们直呼：回去要开科室会，让医生护士们都好好学习一下。
战略需要反复地讲
战略要落地，需要组织上下在思想上互相认同，因而在行为上实现统一。思想认同，则需要反复的传播，需要科主任把战略说到大家的心坎里。

在领导力课堂上，科室主任们第一次用古希腊哲学家的“修辞学”来讲述自己的战略故事，在大家的聆听和反馈中，将自己的故事逐步完善。这样的练习是为了帮助科室主任实现把自己的思想赢得团队的共鸣和认同。
提升领导力 促学科发展

在激烈的思维碰撞中，主任们从新的角度思考了科室的发展方向。大家普通认为，一名成功的皮肤科主任，不仅需要学术造诣深湛，在管理上也需要专业；科学、严谨、高效不仅是医学研究与临床工作的需要，也是团队可持续快速发展的基石。两天丰富的学习内容获得了主任们的强烈好评。可以说，“中国皮肤科主任领导力学院”为学界的人才培养打开了新的窗口，大家临别时依依不舍，相约明年春天北京再聚。据了解，第二次课程将在北京举办，期待更多的皮肤科主任加入后续课程，共同探索学科与团队的发展之路。
